# 军棋封面 v12

以现有游戏引擎生成准确棋盘的独立 Three.js 场景。运行目录为项目根目录：

```sh
node review/junqi-cover/render.cjs
```

脚本使用本机缓存的 Chromium 和软件 WebGL 渲染，输出 `junqi-v12.png`（2560 × 1440）。Chrome 路径位于脚本内，换机器需调整。原图再通过 ffmpeg Lanczos 缩放为正式封面和缩略图。

棋盘每条连接调用引擎 `_isRoadEdge` 与 `_isRailEdge` 判断，普通兵站、行营和大本营按统一坐标生成，线路截断到棋位边界；中央仅保留左、中、右铁路。红方文字朝向镜头，蓝绿方展示暗棋背面。布局是稀疏残局的美术示意，检查了坐标不重叠、军旗和地雷位置限制，但没有完整对局回放证明该残局可达。

本次采用确定性建模与字体渲染，未让图像生成模型重绘棋盘结构。纹理、灯光、相机及棋子列表均在 `render.html` 中，可直接调整后重渲染。
