# 环城大富翁原创棋盘素材

现行棋盘由 `hong-kong-board-frame.png` 与一张中央场景图组合显示；旧合成图、
中间排版稿和未启用备选原画已经移出项目，避免后续误改旧版本。

## 可替换的中央插画

`hong-kong-board-center.png` 是从最终合成图中原像素裁出的中央区域：
`x=198, y=178, width=854, height=900`，宽高比为 `427:450`。

`hong-kong-board-frame.png` 保留 1254×1254 的外圈棋盘、格子文字和装饰，上述
中央矩形的 alpha 值全部为 0。将中央图放在同一坐标的底层，再把外框覆盖在
最上层，即可还原当前棋盘。

替换中央场景时，直接替换 `hong-kong-board-center.png` 即可。建议输出 854×900
或任意 `427:450` 比例的图片；页面使用 `object-fit: cover` 时，其他比例的图片会居中
放大并裁掉多出部分。保持文件名不变便无需修改前端路径。

### 页面换肤

游戏页棋盘右上方的“换肤”菜单内置两款中央画面：

- `hong-kong-board-center.png`：默认“维港纪念”。
- `hong-kong-board-center-neon.png`：备用“霃虹雨夜”。

内置皮肤的选择会记录在浏览器 `localStorage`。“选择本地图片”可用任意图片
临时替换中央画面，文件只在当前页面中使用、不会上传，刷新后恢复上次选中的
内置皮肤。添加新的内置皮肤时，在 `public/games/monopoly/client.js` 的
`BOARD_CENTER_SKINS` 中增加一项即可。

## 玩家棋子

`tokens/` 内是 8 枚对应 2–8 名玩家的香港主题透明 PNG 棋子：双层电车、
渡轮、帆船、的士、灯笼、洋紫荆、缆车和点心笼。前端按玩家数组顺序固定分配，
并使用玩家颜色的外圈区分同一格内的多枚棋子。

单枚文件均为收紧透明留白的 256×256 RGBA。棋子为原创玉绿、象牙、朱红和旧金色琥珐小模型，
不含品牌、商标或文字。

### 2D / 3D 模式

页面棋盘上方的“棋子”控件可以在两种显示模式间切换：

- `2D`：古铜线稿和平涂色，更像棋盘印刷的图标。
- `3D`：统一哑金材质、无方底座的小型立体棋子。

模式选择会保存在浏览器 `localStorage`，不会改变棋盘格子或玩家分配。
`token-sheet-2d.png` 和 `token-sheet-3d.png` 保留了两套图标的原始排版，单枚资源使用
`2d-*.png` 与 `3d-*.png` 命名。

最终图片不包含 Monopoly 标志、角色、卡牌或原版棋盘文字。玩家、地产归属、
建筑和交互状态仍由前端透明图层实时覆盖。

前端按照 1254×1254 外框逐条量取分隔线，以百分比绝对
坐标放置 40 个透明交互格。四角保留近正方形，普通边格只覆盖米色纸面；外侧约
26px 的金绿装饰框、内侧绿色饰边和格间金线不属于任何虚拟格子。
