# 大厅游戏封面

本目录保存 28 款游戏的本地横版高清封面，统一为 `1280 × 720` WebP。`thumbs/` 子目录保存同名 `640 × 360` WebP 缩略图：大厅游戏卡片和公开房间列表按可见范围懒加载缩略图，创建房间规则浮窗与预开局房间继续使用高清封面；BGG 资源仅继续用于部分游戏内部的组件和牌面参考。

封面不采用单一画风，只统一横版规格、缩略图可读性、界面文字留白和无标题/无标识约束。各游戏的主要艺术方向如下：

- 社交推理：狼人杀（哥特电影场景）、阿瓦隆（中世纪手抄本）、猎巫镇（民俗木刻）。
- 解密类：谍报风云（冷战瑞士平面）、猜数字（蓝图黑色电影）。
- 棋类与棋盘：国际象棋（明暗静物）、中国象棋（水墨矿物色）、斗兽棋（自然志版画）、军棋（构成主义战术图）、飞行棋（复古未来旅行海报）、五子棋（极简墨绘）、跳棋（玻璃静物）、环城大富翁（港风电影拼贴）。
- 卡牌与策略：情书（洛可可纸艺）、政变（装饰艺术政治海报）、大富翁纸牌（波普拼贴）、牛头王（表现主义木刻）、花火（日式木版画）、璀璨宝石（新艺术装饰画）、多米诺王国（故事书水粉）、并购（世纪中叶企业建筑图）、富饶之城（文艺复兴城市版画）、拉斯维加斯（六十年代旅行海报）、马戏星探（孔版印刷）、马尼拉（旧旅行画）、现代艺术（包豪斯拼贴）、狂野骆驼（沙漠丝网印刷）、胡闹运动会（运动漫画与超现实拼贴）。

生成方式：Codex 内置图像生成工具。生成原图保留在 Codex 资源目录，本目录文件为项目使用的压缩成品。

缩略图生成：使用 `ffmpeg` 以 Lanczos 缩放到 `640 × 360`，WebP quality 76；28 张缩略图总计约 `0.997 MiB`。文件名与高清封面一一对应，便于大厅按游戏类型切换资源而不引入额外映射文件。

版本说明：狼人杀当前使用 `werewolf-v5.webp`。月亮位于最左侧，巨大的狼影由云雾和夜色构成；相较 `v4` 提高了暗部明度，并让狼背融入平整的蓝色夜雾，在画面上半部形成低细节留白。此前版本均保留用于回退。

阿瓦隆当前使用 `avalon-v4.webp`：完整圆桌是绝对视觉中心，场景统一为废弃圆形议事厅；十张座位按每隔 36° 均匀围绕圆桌，全部朝向桌心，六点方向的前排座位自然遮挡少量桌沿。城堡、海岛、圣杯和长剑均已移除，桌面裂痕单独表达内部背叛。此前版本均保留用于回退。

谍报风云当前使用 `decrypto-v2.webp`：保留俄国构成主义、冷战技术海报和瑞士国际主义的几何语言，将旧版电报机下方凌乱的软线重画为四条等粗、无交叉的红蓝信息路径，并简化为四个对应插口。`decrypto.webp` 保留用于回退。

国际象棋当前使用 `chess-v2.webp`：场景改为明亮晨光下的旧棋室，盘面只保留双王、双车与单兵组成的卢塞纳式经典残局；其余被吃棋子全部离开棋盘，少量倒伏在桌面，其余收入左右棋盒。`chess.webp` 保留用于回退。
