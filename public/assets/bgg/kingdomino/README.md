# Kingdomino visual assets

- Lobby cover: [BGG image 8443569](https://boardgamegeek.com/image/8443569/kingdomino).
- Terrain source: [BGG image 3327248](https://boardgamegeek.com/image/3327248/kingdomino), original size 2259×2213.
- Active terrain crops: `wheat-1..4.jpg`, `forest-1..4.jpg`, `sea-1..4.jpg`,
  `meadow-1..4.jpg`, `swamp-1..4.jpg`, and `mine-1..3.jpg`.

The active crops use the interior of correctly identified terrain squares and omit printed crowns. Runtime HTML/CSS supplies the scoring crowns, order number, hidden-tile back, castle, and rule example. Superseded unnumbered crops and the source photo are not retained in the current-version directory.
