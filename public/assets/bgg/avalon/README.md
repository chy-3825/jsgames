# 阿瓦隆角色美术

游戏内角色牌来自 BoardGameGeek 上同一英文基础版的两张高清实体牌合照，并在本项目内完成透视区域裁切、统一为 `720 × 900` WebP：

- 善良阵营：[BGG 图片 1453098](https://boardgamegeek.com/image/1453098/the-resistance-avalon)，原图 `4161 × 3069`，上传者 `joakim589`。
- 邪恶阵营：[BGG 图片 1453075](https://boardgamegeek.com/image/1453075/the-resistance-avalon)，原图 `4023 × 3050`，上传者 `joakim589`。

`roles/` 下的八张文件分别对应当前规则引擎的 `loyal`、`merlin`、`percival`、`minion`、`assassin`、`morgana`、`mordred` 和 `oberon`。裁图只承担人物美术层；中文名称、阵营、能力、私密线索及交互状态仍由实时 HTML 数据渲染。

这些资源沿用项目已确认的 BGG 使用许可，仅供本项目界面使用。若更换版本或授权范围，应同时更新本文件与上级 `SOURCES.md`。
