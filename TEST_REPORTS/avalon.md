## 身份档案交互与阵营色泄露修复（2026-08-29）

- 定位到两个前端问题：角色容器一直带 `is-good`/`is-evil` 阵营变量，牌背状态仍会露出顶部边框和光晕；按住事件只在局部监听 `pointerup`，缺少移出检测、窗口级取消和活动指针校验，长按过程中发生重绘或多指操作时可能让档案停在不可再次打开的状态。
- 角色容器现在默认使用中立色，仅在身份真正显示时临时挂载阵营 class；隐藏状态还由 CSS 中立兜底，避免旧 DOM 状态残留造成颜色泄露。
- 统一按住生命周期：活动指针 ID 防抢占，窗口级 `pointermove`/`pointerup`/`pointercancel`、移出边界、失焦、后台切换和右键菜单均会收束身份；新一局进入身份确认时重置“已查看”状态，确认按钮不会沿用上一局的亮起状态。
- 新增指针边界/取消/多指与阵营色回归断言；资源版本更新为 `20260829-avalon-role-privacy-1`。
- 验证结果：阿瓦隆专项 **7/7**；Firefox 浏览器级隐私输入检查通过（含键盘、触摸、失焦及隐藏阵营色）；最终 `npm test` **532/532**、语法检查 **395 个文件**、Firefox 导入 **28/28** 与视觉 fixture **96/96**，完整 acceptance gate **PASS**。

## 首轮身份卡稳定性修复（2026-08-29）

- 定位到首轮按住身份牌时的偶发失效：遮罩按钮在 `pointerdown` 后立即切换为 `visibility:hidden`，部分浏览器会发出同位置的 `pointerout/focusout`，导致身份刚显示就被收回。
- 身份显示期间保留透明遮罩的命中区域，并对 `pointerout` 做几何边界判断；只有指针真正离开卡片才封存，鼠标、触摸和键盘释放仍会立即封存。
- 开场身份播报层改为只负责信息展示、不拦截指针；身份播报仍在播放时，首轮身份栏提升到播报层之上，避免低动效/快速首帧下卡片被遮挡。
- 同步更新入口与测试页资源版本，避免浏览器继续使用旧的身份交互代码。
