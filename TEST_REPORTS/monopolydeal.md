# 大富翁纸牌（Monopoly Deal）测试报告

- 状态：通过本轮正式规则验收，可进入下一款游戏。
- 人数：2–5 人；本轮使用 5 人最大人数进行了 3 局完整流程测试。
- 测试命令：`node --test test/monopolydeal-official.test.js`、`node --test test/regression/monopolydeal.test.js`，随后执行项目全量 `npm test`。
- 本轮专项：6/6 通过；当次项目回归：167/167 通过；与其他专项合并后的当次项目全量结果为 189/189 通过（历史快照）。
- 规则依据：[Hasbro 游戏说明](https://instructions.hasbro.com/en-gb/instruction/monopoly-deal-card-game)、[Hasbro 牌组与起始流程 PDF](https://www.hasbro.com/common/documents/dad288661c4311ddbd0b0800200c9a66/6cde82515056900b10f41868ca079dc6.pdf)、[Hasbro 支付 FAQ](https://hasbro-new.custhelp.com/app/answers/detail/a_id/944/~/monopoly-deal---which-cards-can-i-use-to-pay-other-players%3F-%28e.g.-for-rent%2C)。

## 规则逐条核对

| 规则 | 结果 | 验证内容 |
| --- | --- | --- |
| 牌组 | 通过 | 110 张盒装牌；移除 4 张规则卡后 106 张可玩牌；28 张普通地产、11 张地产万能牌、20 张现金、13 张收租、34 张行动牌。 |
| 人数与发牌 | 通过 | 2–5 人；每人起手 5 张；五人局起始后牌库剩 81 张。人数不在范围内时不能开始。 |
| 摸牌 | 通过 | 通常回合摸 2 张；回合开始没有手牌时摸 5 张；牌库耗尽时只从弃牌堆重洗，不会把银行牌洗回牌库。 |
| 出牌与手牌上限 | 通过 | 每回合最多打出 3 张；“说不”不计入 3 张；回合结束超过 7 张进入弃牌阶段并弃到 7 张。 |
| 银行 | 通过 | 现金、行动牌和收租牌可作为银行资产；存入银行的行动牌永久是现金，不能再当行动发动；银行牌公开显示且不会重洗。地产不能放入银行。 |
| 地产组 | 通过 | 同色可有多个独立组；每组不能超过牌面数量；同色多个完整组只计一种胜利颜色；完整组至少含一张普通地产。 |
| 地产万能牌 | 通过 | 双色万能牌可单独起组、可收租、可支付并能在自己回合免费换色；十色万能牌可放置但单独不能收租或完成地产组；纯万能组不能直接获胜。 |
| 建筑 | 通过 | 房屋只能放在完整的非铁路/公用事业组；酒店必须先有一张房屋；每组最多一房一店；房屋 +3M、酒店另 +4M。 |
| 拆组建筑 | 通过 | 拆散带建筑的地产组时，房屋/酒店转入原拥有者银行，不进弃牌堆；附着建筑不是可直接点选的地产支付牌。交易破坏者夺取完整组时建筑随整组转移。 |
| 收租 | 通过 | 双色收租选择一个支持颜色并向所有其他玩家依次收租；十色收租指定一种颜色和一名玩家；孤立十色万能牌不能收租。 |
| 双倍租金 | 通过 | 必须紧接合法收租牌；最多两张双倍租金，合计最高四倍；未接收租不能结束回合。 |
| 债务与支付 | 通过 | 对手先接受或使用“说不”，之后欠款人从桌面银行牌/地产牌中自行选择；不找零；资产不足时交出全部所选可支付资产，余债结清；手牌不能支付。 |
| 行动牌 | 通过 | 生日收礼向所有对手各收 2M；收取债务向一人收 5M；通过起点摸 2 张；偷偷交易/强制交换不能触碰完整组；交易破坏者夺取完整组及建筑。 |
| 说不 | 通过 | 只对当前针对自己的行动生效，可由另一张“说不”反制；整个回应链不占行动者的三张出牌额度，且不会泄露对方是否持有该牌。 |
| 胜利 | 通过 | 一名玩家拥有三个不同颜色的完整地产组时立即结束；直接放置、支付收地产、偷偷交易、强制交换和交易破坏者后都会立即重算胜利。 |

## 三局五人完整流程

为避免随机牌序导致报告不可复现，三局均从真实 5 人发牌开始，再将已验证的合法测试牌注入各玩家手牌；之后所有动作均通过大厅 Room → Session → Engine 的真实接口完成，未直接调用内部结算函数。

### 第 1 局（种子 201，A 获胜）

1. A、B、C、D、E 五人进入房间，A 先手；每人收到 5 张。
2. 为覆盖胜利流程，A 依次打出棕色两张、浅蓝三张、粉色三张地产；B、C、D、E 各完成一次摸牌、将现金存入银行并结束回合。
3. A 的三个回合分别完成棕色组、浅蓝组和粉色组；每次结束前均不超过 7 张手牌。
4. A 放下第三个不同颜色完整组后立即触发胜利，房间状态变为 `ended`，赢家为 A。

### 第 2 局（种子 202，C 获胜）

1. 五人重新发牌，仍由 A 开始；A、B 先完成摸牌、存入现金和结束回合，C 获得第一回合。
2. C 跨三个自己的回合完成棕色、浅蓝、粉色三组；D、E、A、B 在 C 的回合之间正常轮转。
3. C 放下第三个完整组后立即结束；五名玩家均至少实际完成一个回合，未出现卡住或越权操作。

### 第 3 局（种子 203，E 获胜）

1. 五人重新发牌并按 A→B→C→D→E 顺序轮转；前四名玩家均完成摸牌、出牌/存银行和结束回合。
2. E 在自己的三个回合完成棕色、浅蓝、粉色三组，过程中保持每回合最多三张。
3. E 放置第三组后触发胜利；状态、赢家、公开银行和地产组均与终局一致。

## 本轮发现并修复

1. 修复大厅适配器未把 `gameOptions.random` 传给大富翁纸牌引擎的问题，使五人测试和复现牌序可靠。
2. 修复拆散地产组时房屋/酒店被错误丢入弃牌堆的问题，改为进入原拥有者银行。
3. 修复支付界面把附着房屋/酒店当作可直接支付资产的问题；现在只能选择桌面银行牌和地产牌，拆组后的建筑按规则进入付款人银行。
4. 同步更新客户端规则说明、债务支付选项和银行账本提示，避免把建筑状态误导成可支付牌。
