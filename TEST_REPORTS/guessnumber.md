# 猜数字（Bulls & Cows）最高验收报告

## 验收结论

猜数字是严格单人游戏。本轮按单人正式规则完成逐条核对、输入边界测试、答案隐私测试和 3 局完整流程测试，结果：**通过，10/10**。

规则范围：四位互不重复数字、A/B 反馈、猜测次数不限；不加入计时、次数上限或多人轮流变体。

全量测试基线已从本报告初版的 231 项扩展；本轮验收以当前 `npm test` 实际结果为准。

## 规则逐条核对

| 规则 | 实现结果 |
| --- | --- |
| 人数 | `metadata` 明确限制为恰好 1 人；多人启动直接拒绝。 |
| 答案 | 开局从 0–9 中随机抽取 4 个不重复数字；答案只保存在服务端，进行中公共状态和玩家状态均返回 `secret: null`。 |
| 输入 | 必须是恰好 4 位 ASCII 数字，四位不能重复；空串、长度错误、非数字和重复数字均拒绝，且不消耗次数。 |
| A | 数字和位置同时正确的数量，逐位计算。 |
| B | 数字存在但位置错误的数量，用“命中数字总数 − A”计算，不会重复计算。 |
| 反馈 | 每次合法猜测写入历史和最近反馈；`A+B+未出现=4`。 |
| 次数 | 不设上限；连续 10 次、11 次或更多错误都保持 `playing`，仍可继续猜。 |
| 胜负 | 恰好 4A 时立即进入 `ended`，公布答案和胜者；结束后继续提交会被拒绝。 |
| 回合 | 单人局始终由同一玩家行动，不存在错误轮换或跳过。 |
| 重启 | 已开始或已结束的引擎/Session 不能重复开始；测试可注入随机源复现牌序。 |

## 本轮修复

1. 引擎 `start()` 增加状态门槛，避免结束后直接重置答案、历史和胜者。
2. Session 支持房间传入 `random`，用于确定性复盘和自动化验收，正式房间仍使用系统随机数。
3. 开局统一清理回合标志、历史、结果和胜者，确保合法的全新等待状态只有一次初始化路径。

## 三局完整对局

三局均从真实 Session 开始，通过 `handleAction('a', { kind: 'submitGuess', guess })` 逐次猜测，未直接调用终局函数。测试控制器读取引擎私有答案仅用于生成合法测试策略，真实前端不会收到答案。

| 对局 | 流程 | 结果 |
| --- | --- | --- |
| seed 2001 | 轮换、反转等 3 次合法错误猜测后提交答案 | 4A，答案公开，玩家 a 获胜 |
| seed 2002 | 3 次合法错误猜测后提交答案 | 4A，正常结束 |
| seed 2003 | 3 次合法错误猜测后提交答案 | 4A，正常结束 |

另有一局专门连续提交 11 次错误猜测，状态始终保持 `playing`，第 12 次提交正确答案后才结束。

## 前端验收

- 数字键盘只允许输入 4 个不重复数字，重复数字不会再次加入槽位。
- 清除和提交均为明确按钮，按钮具备 `focus-visible` 焦点样式和禁用状态；离房由大厅统一外壳负责。
- 左侧显示当前输入槽位，右侧显示次数、当前回合和最近 12 条 A/B 历史反馈。
- 进行中不显示答案；结束状态明确显示猜中玩家和最终答案。
- 740px 以下切换为移动端单列布局，键盘和历史记录仍可用。

## 前端可用性补强（2026-08-27）

- 修复提交后等待服务器期间仍可用实体键盘输入、再次提交的竞态窗口；屏幕键盘和键盘快捷键现在使用同一提交锁。
- 当前位数、已输入数字、重复数字拒绝、提交中和反馈返回均通过 `aria-live` 向读屏器播报。
- 规则弹层支持打开聚焦、`Tab` / `Shift+Tab` 循环、`Escape` 关闭、关闭后焦点恢复和 `inert` 背景隔离。
- 844×390 与 667×375 短横屏使用“目标密码/最近反馈 + 当前输入/数字键盘”双栏，提交按钮保留在核心视口。
- 统一外壳视觉 fixture 新增 `guessState=empty|ready|feedback|ended`，规则弹层继续使用通用 `rules=1` 状态验收。
- 新增 `test/guessnumber-frontend.test.js`，覆盖提交锁、读屏播报、弹层焦点和短横屏 fixture 完整性。
- 本轮复跑猜数字专项与前端检查 8/8 通过，项目全量测试 391/391 通过。

## 终局解密播报（2026-08-27）

- 从进行中进入结束状态时触发全屏结算，普通错误猜测仍使用局部 A/B 反馈，不打断连续推理。
- 正常结局按“4A 0B → 四位答案依次解密 → 破解者与总尝试次数”播放。
- 无胜者的异常结束显示“调查中止 / 档案封存”，不会误报破解成功。
- 结算支持跳过、`Escape` 快速结束和减少动态效果。
