# 游戏大厅专项验收报告

更新日期：2026-08-29；适用版本：`2.1.0`

本文件只记录大厅当前可维护的验收结论。按批次追加的旧日志已移至
[`lobby-history.md`](./lobby-history.md)，其中的测试数量、缓存版本和云端快照均属于当时运行记录，不能覆盖本文件或
[`phase4-runtime.md`](./phase4-runtime.md) 的当前基线。

## 当前结论

- 服务端 registry 返回 28 款正式游戏；大厅分组、人数、运行模式和房间设置均从服务端元数据生成。
- “开始游戏 / 加入房间”入口、规则说明、房间设置、公开房间筛选和房间号直达均可用；创建请求只在最终确认后发送。
- 等待房间为服务端权威状态：房主权限、稳定 `seatIndex`、准备状态、人数门槛、房间设置和踢人均由服务端再次校验。
- 游戏开始后只保留统一外壳提供的一个离房入口；客户端销毁时会清理挂载点、事件监听和动态资源。
- 非主动断线保留席位并暂停对局；30 秒宽限期内可凭会话令牌恢复原玩家、座位和视角。主动离房不会进入重连流程。
- WebSocket 默认执行同源/显式 Origin 校验、256 KiB 负载上限、JSON 结构限制、会话/IP/房间限流、聊天清洗和 30 秒心跳；人工重连必须携带原会话令牌。
- `/healthz` 提供版本、房间/连接计数和 `no-store` 响应；Express 统一发送 CSP、`X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy` 与 `Permissions-Policy`，HTTPS 请求附加 HSTS。
- 隐藏身份、花火牌背和谍报风云关键词/密码的显示边界已接入浏览器自动化；真实多浏览器和移动设备签字仍未完成。

## 房间协议与权限

| 能力 | 当前验收结果 | 证据 |
| --- | --- | --- |
| 创建/加入/公开列表 | 28 款游戏均可经 `registry → Room` 创建；仅邀请房间不出现在公开列表，但可按房间号加入 | `npm test`、`npm run test:browser` |
| 配置与准备 | 房主可设置有效人数/专属选项；设置变更会清除成员准备；未满足人数或准备条件时服务端拒绝开局 | `test/room*.test.js`、全量回归 |
| 身份与座位 | WebSocket 首次分配唯一 `playerId`/`sessionToken`；同标签会话不会抢占仍在线的连接；加入/离开不重排既有座位 | `npm run test:browser` |
| 断线恢复 | 房间暂停、会话令牌重连、原座位/玩家状态恢复、全部断线成员回来后恢复；在线玩家 ID 会被拒绝重复使用 | `npm run test:browser` |
| 房主操作 | 只有房主可开始、改设置和踢出等待成员；游戏开始后不能踢人 | `npm test` |
| 生命周期清理 | 主动离房、空房间删除、成员离开后的房主转移和游戏客户端销毁均有回归覆盖 | `npm run test:performance`、`npm run test:browser` |

## 界面与信息边界

- 游戏卡片先打开规则浮窗，再进入房间属性设置；房间名称、可见性和人数范围在服务端归一化并再次校验。
- 等待房间按当前玩家旋转席位，使用蓝焰/灰焰/金色状态文字表达入座、未准备和房主状态；开局演出不会改变协议顺序。
- 公共游戏外壳固定 48px 顶栏、单一离房出口、安全区和 `100dvh`；游戏内部的次要信息才进入显式滚动容器。
- 身份牌采用“按住显示、松开/失焦立即封存”；花火本人只见牌背，队友牌面才公开；谍报风云关键词和密码按队伍/加密员权限隔离。
- 讨论型游戏只提供公共文字/语音边界提示，不把页面描述为内置音视频系统。

## 当前未签字项

- Firefox 之外的真实桌面浏览器、真实 iOS/Android 设备、弱网和浏览器后台恢复仍需人工签字。
- 目标服务器上的 systemd 安装、Nginx/HTTPS、安全组、备份、回滚和预发布容量压测仍需在目标环境执行。
- 生产前仍需按 [`security.md`](./security.md) 校准公网阈值、完成空闲业务超时/多实例策略和预发布监控；Origin、消息大小/频率、重连凭证与基础安全头已有本地自动化证据。

## 架构收尾（2026-08-29）

- `public/script.js` 现在约 1100 行的组合入口；目录、传输、加载器、封面/组件图、创建弹层、等待桌、入场转场和棋谱控件分别位于 `public/lobby/`，入口只保留状态编排和协议路由。
- 并购、阿瓦隆、富饶之城、政变的长样式已拆成基础与版图/私有信息/交互/场景/响应式层，并由 `public/games/common/game-manifest.js` 按固定顺序加载；四个静态视觉页同步使用同一层级。
- 胡闹运动会引擎已拆出 `constants.js`、`movement.js`、`turn-resolution.js` 和 `state.js`，引擎本体保留生命周期编排；新增架构回归会阻止入口重新膨胀或样式脱离资源清单。
- 架构与实时安全回归、全量 `npm test` 均为 **509/509**；Firefox **28/28 模块、96/96 视觉夹具**和 Chromium **28/28 模块、72/72 视觉夹具**均通过。
