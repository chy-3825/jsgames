# 并购（Acquire）测试报告

## 验收范围

本次按 Avalon Hill 经典版规则验收，不混用后续 100 块棋盘版本。规则依据 [Avalon Hill 官方规则书](https://media.wizards.com/2015/downloads/ah/acquire_rules.pdf)；官方产品资料也确认并购是 2–6 人、以股票和酒店集团资产决胜的游戏。[Hasbro 产品页](https://instructions.hasbro.com/en-us/instruction/acquire)

经典版口径：108 块地块、9×12 地图、7 个集团、每集团 25 股、每人 6,000 元和 6 块手牌；11 格以上为安全集团，41 格以上或所有集团安全时可宣布结束。

## 逐条规则核对

| 规则项目 | 实现与验证结果 |
| --- | --- |
| 开局与先手 | 每位玩家先抽 1 块起始地块放到对应坐标；起始地块保持中立，即使相邻也不会立即成团；编号最小者先手。随后每人获得 6 块隐藏手牌。 |
| 地块与集团 | 所有 108 个坐标唯一；铺设后，单独地块保持中立；相邻中立地块可创建集团；创建者获得 1 股创始人股票并吸收相邻中立地块。 |
| 股票 | 集团启用后按集团等级和规模计算股价；每回合最多购买 3 股，受现金和 25 股库存限制。 |
| 合并 | 连接两个或更多集团时，规模最大的集团存续；同规模由引发合并者选择。两个安全集团不能合并，单个安全集团可以吞并开放集团。多集团合并按被吞并集团规模从大到小结算。 |
| 股东红利 | 唯一持股者获得多数和少数两项红利；多数平局合并两项红利后平分；少数股东按第二高持股数平分少数红利，金额按规则向上取整到百元。 |
| 合并股票处理 | 每位持股者必须完整分配旧股：卖出、按 2:1 换成存续集团股票或保留；换股受存续集团库存限制。 |
| 不可玩地块 | 只有会连接两个安全集团的永久不可玩地块可弃置；会造成第八个集团的暂时不可玩地块不能直接弃置。若整手牌没有合法铺设，玩家可跳过铺设并继续购股。 |
| 回合补牌 | 玩家完成铺设/弃置、购股后，补牌给刚完成行动的玩家；下一位玩家不会提前摸牌。 |
| 终局 | 宣布结束后仍完成当前回合交易，再发放所有存续集团终局多数/少数红利，按集团规模清算全部股票；未在棋盘上的集团股票价值为 0，现金最多者获胜。 |

## 最大人数完整对局

测试控制 6 名玩家 a–f，采用确定性随机种子。每回合自动寻找合法地块；永久不可玩地块才弃置；没有任何合法地块时使用跳过铺设；创建集团、合并选择、股东处理和购股均实际执行。三局都从起始地块、完整牌库和隐藏手牌开始，直到牌库与手牌耗尽并完成终局清算。

## 本次修复

1. 增加经典版起始地块抽取、先手排序和起始中立地块。
2. 创建集团时补发创始人股票。
3. 修正多数平局、唯一股东和少数平局的红利算法。
4. 修正安全集团规则：安全集团可以吞并开放集团，但两个安全集团不能合并。
5. 修正补牌对象：补给刚完成回合的玩家，而非下一位玩家。
6. 增加永久不可玩地块校验、整手无合法铺设时的跳过流程，以及第八集团暂时不可玩限制。
7. 增加正式终局流程：当前回合完成后发放终局红利、按集团规模清算股票并以现金决胜。
8. 增加随机源注入和重复开始保护，便于大厅运行和复现测试。
9. 前端同步起始顺序、创始人股票、安全集团、不可玩地块、跳过铺设和终局清算说明；不可玩地块按钮不再伪装成普通可弃置牌。
10. 所有前端行动增加统一提交锁，服务端状态或错误返回后恢复，避免铺砖、购股和股东结算重复提交。
11. 规则与高影响决策弹层增加背景隔离、Tab 焦点循环和关闭后的焦点归还。
12. 增加持续可见的操作错误提示，并让所有公共演出都可主动跳过。
13. 增加手机短横屏布局与统一视觉夹具，覆盖七种关键牌局状态。
