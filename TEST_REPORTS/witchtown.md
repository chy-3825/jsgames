# 猎巫镇（Salem 1692 标准核心版）测试报告

## 验收结论

本次按官方基础版 4–12 人规则重新核对并完成代码验收：**通过**。当前实现范围是基础版 59 张游戏牌、15 张 Town Hall 角色牌；Deluxe 的额外 Trial 牌、2–3 人变体和实体主持人沙漏不在范围内。

测试命令：

```bash
npm test
```

结果：**329/329 通过**（其中包含 8 项猎巫镇专项测试和 8 项猎巫镇跨层回归测试）。

规则依据：[Salem 1692 官方规则 PDF](https://board-game-rules.com/wp-content/uploads/2025/01/salem-1692_Official-Rules.pdf)、[Tabletopia 官方规则页](https://c.tabletopia.com/games/salem/rules/salem-rulebook-5th-edition/en)。

## 逐条规则核对

| 规则 | 实现与测试结果 |
| --- | --- |
| 4–12 人人数范围 | `TRIAL_SETUP` 覆盖 4、5、6、7、8、9、10、11、12 人；超范围拒绝开始。专项测试逐人数核对 Town/Witch/Constable 数量和每人 3–5 张审判牌。 |
| 审判牌 | 各人数按官方表发放 Town、Witch、Constable；Witch 总数保存在开局设置，不会因阴谋移动或出局导致错误提前胜利。 |
| 开局核对 | 发牌后先进入密封档案核对阶段。每位玩家只能确认一次；所有存活玩家确认后，流程自动进入女巫选择黑猫的黎明阶段。 |
| 游戏牌 | 35 指控、5 证据、1 目击者、3 不在场证明、1 纵火、1 诅咒、1 抢劫、2 替罪羊、3 枷锁、1 避难所、2 红娘、1 虔诚，加黑猫、阴谋、夜幕，共 59 张。黑猫不进牌库，阴谋洗回牌库，夜幕位于牌库底。 |
| 黎明黑猫 | 所有女巫私密提交，服务端按多数票、座位顺序破平票；黑猫持有者先手。每位玩家只能看到自己的审判牌类型，其他玩家的未揭示牌仍为私密。 |
| 白天行动 | 每回合只能选择“摸两张并结束”或“打出至少一张牌”；打牌后可继续打牌，最后显式结束。未摸牌/未打牌不能空过。夜幕不由主持人跳过，只在抽到夜幕牌时自动进入夜晚。 |
| 红牌 | 指控 1 点、证据 3 点、目击者 7 点；通常累计 7 点揭示一张审判牌，George Burroughs 为 8 点，Thomas Danforth 的特殊阈值按角色组合执行；揭示后红牌全部弃置，超出点数不结转。 |
| 绿牌 | 不在场证明、纵火、诅咒、抢劫使用后进入弃牌堆；Sarah Good 可使纵火/抢劫对自己无效；Will Griggs 可把不在场证明当 7 点目击者使用。 |
| 蓝牌 | 枷锁、避难所、红娘、虔诚留在目标面前并按效果生效；枷锁逐次跳过回合，避难所保护夜晚，红娘连带出局，虔诚使红牌无效。蓝牌不会同时出现在玩家面前和弃牌堆。 |
| 替罪羊/抢劫 | 两张目标必须是不同的其他玩家，不能让出牌者获益；只剩两名玩家时不能合法使用。替罪羊移动目标面前的红牌和蓝牌，抢劫移动一名玩家的全部手牌。 |
| 阴谋 | 抽到者先选择黑猫持有者的一张未揭示审判牌，然后仍存活玩家按顺时针从左手玩家的快照中秘密取牌。若揭示导致黑猫持有者死亡，交换顺序会即时移除死亡席位。传递后重新洗乱每份档案，并要求所有存活玩家重新核对，完成后才恢复被中断的摸牌或白天流程。 |
| 公开证据 | 未揭示审判牌只公开数量；已经揭示的审判牌会公开类型，并通过带序号的揭示事件驱动客户端审判转场。 |
| 夜幕 | 夜晚按女巫、警长、全员认罪决定三个步骤自动推进。女巫全部封存决定后才轮到警长；警长完成后所有存活玩家必须选择认罪或沉默；全部决定完成后自动天亮，不存在主持人推进权限。击杀平票、法槌、认罪或避难所都会使目标存活。 |
| 认罪 | 夜晚可揭示自己的普通审判牌换取本夜击杀免疫；免疫只持续当前夜晚。William Phips 每局一次可以不揭示审判牌完成认罪，该能力有独立专项测试。 |
| 出局与胜负 | 翻出 Witch、翻完全部审判牌或夜晚被击杀会出局并公开剩余审判牌；John Proctor 接收出局者手牌/蓝牌。全部 Witch 牌揭示则镇民获胜，所有存活者都曾持有 Witch 牌则女巫获胜。 |

## 本次修复内容

1. 开局增加全员审判档案核对门槛；客户端以密封档案遮盖阵营与审判牌，镇议会人物继续作为公开信息展示。
2. 阴谋传递完成后重新洗乱审判牌，并进入第二轮全员档案核对；核对结束后准确恢复被中断的摸牌与回合。
3. 删除夜晚房主推进，改为女巫、警长、认罪窗口依次自动推进；“保持沉默”也必须明确确认，避免流程无法判断何时结束。
4. 增加 William Phips 免揭示认罪、公开审判证据、档案进度和夜间进度的权威状态。
5. 客户端增加夜幕、天亮、阴谋、审判牌揭晓、个人出局和最终判决的分级全屏转场；个人出局需主动确认后以破碎效果回到观战流程。
6. 修正开局审判牌洗牌结果未被用于实际发牌的问题。
7. 修正夜间死者恰好是次日起始玩家时，白天可能落在已出局席位的问题。
8. 保留并验证原有白天二选一、牌区、黑猫死亡空席位、隐私和 `totalWitches` 胜负快照规则。

## 完整对局记录（最大人数 12 人）

三局均由服务端状态机驱动 12 名玩家，从全员核对档案、黑猫选择、白天摸牌/出牌、阴谋传递与再次核对，到女巫、警长、全员认罪决定和自动天亮，最终自然完成胜负结算。自动玩家只使用当前状态公开的合法动作，整个流程不调用主持人推进接口。

| 对局 | 过程 | 结果 | 缺陷 |
| --- | --- | --- | --- |
| seed 801 | 12 人；完整经历档案核对、白天、阴谋或夜间状态 | 自然结束并产生胜者 | 无 |
| seed 802 | 12 人；独立洗牌并完整执行全部可达状态 | 自然结束并产生胜者 | 无 |
| seed 803 | 12 人；独立洗牌并完整执行全部可达状态 | 自然结束并产生胜者 | 无 |
