# 大富翁纸牌轻量代码体检（2026-09-08）

本轮以现有工作区为基线，保留既有视觉方案和规则，清理可证实的历史遗留。

## 已处理

- 删除被图片牌面替代的几何插画生成器、ACTION_MARKS、色条生成器及配套旧样式；未知牌使用简单文字回退。
- 完整牌面统一 article 包装，地产/租金等内容只生成一次，不再为每种牌重复拼接相同属性。
- 清除已被原版图片替代的普通地产表格分支，保留现用万能地产布局。
- 将现用卡面样式从资产浮窗文件归回卡片基础样式；不增加样式请求或调整加载顺序。
- 共享牌面验收页调用实际渲染函数，消除旧版假卡面。
- 服务端牌库定义抽出到 deck.js，保留 engine.js 的原有导出接口。
- 修复“做出反对”图片的 3M 与规则 4M 不一致：两个角标使用服务端面额显示，手牌及公共卡面共用。
- 收紧相关文件行数门禁。

## 验证

- 46 项专项测试通过：牌面、前端、正式规则、演出及回归。
- 拆分前后 110 张牌的完整定义深比较一致；106 张可玩牌均有现用牌面。
- 相关 JS 的 ESLint 通过；复杂度门禁通过。
- 使用现有 Chromium 检查脚本的临时限定版运行本游戏：1280×900、390×844、844×390 三种尺寸通过，5 个客户端入口导入通过。
- 实际渲染的共享牌面页截图检查通过，两个反对牌角标显示 4M。

## 规模与后续边界

- engine.js：1763 → 1683 行；新增 deck.js：84 行。
