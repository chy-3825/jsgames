# 规则验收矩阵

更新日期：2026-09-15。 本矩阵是 28 款游戏规则状态的唯一汇总入口；每个游戏报告仍保留逐条证据、完整对局和已知限制。

## 状态定义

- **正式规则已签署**：指定版本/人数/变体已有规则来源、逐条核对、边界测试和完整对局证据。
- **可玩回归通过**：正常对局和已编写场景通过，但仍缺少足以签署全部官方规则的来源、边界或人工裁定。
- **规则边界待签署**：基础规则可运行，竞赛裁定、项目自定义规则或特殊变体尚未形成签字范围。

本次本机验收的 `npm test` 为 733/733；它只表示当前已编写测试通过，不会自动把“可玩回归通过”升级为“正式规则已签署”。
